# javascript-racingcar-precourse

## 구현할 기능 목록

### 1. 입력 기능
- [x] 경주할 자동차 이름을 입력받는다.
  - 쉼표(,)를 기준으로 분리한다.
  - 각 이름은 1자 이상, 5자 이하인지 검증한다.
  - 공백 이름 또는 중복 이름이 있을 경우 `[ERROR]`를 출력한다.
- [x] 시도할 횟수를 입력받는다.
  - 정수 형태로만 입력받으며, 1 이상의 숫자인지 검증한다.
  - 잘못된 입력일 경우 `[ERROR]`를 출력한다.

---

### 2. 게임 진행 기능
- [x] 각 자동차의 현재 위치를 저장한다.
- [ ] 시도할 횟수만큼 반복하여 자동차를 전진 또는 정지시킨다.
  - `MissionUtils.Random.pickNumberInRange(0, 9)`를 통해 랜덤 값을 생성한다.
  - 랜덤 값이 4 이상일 경우 자동차가 전진한다.
- [ ] 매 시도마다 자동차의 이동 결과를 출력한다.
  - 예시: `pobi : ---`

---

### 3. 우승자 판별 기능
- [ ] 가장 멀리 이동한 자동차(들)을 계산한다.
- [ ] 여러 대가 같은 거리일 경우 쉼표(,)로 구분하여 모두 출력한다.
  - 예시: `최종 우승자 : pobi, jun`

---

### 4. 예외 처리
모든 예외 상황은 `[ERROR]`로 시작하는 메시지를 출력하고 프로그램을 종료한다.  
(`process.exit()`는 사용하지 않는다.)

#### 입력 관련 예외
- [x] 자동차 이름이 비어 있거나 존재하지 않을 경우  
  → `[ERROR] 자동차 이름을 입력해야 합니다.`
- [x] 이름에 공백(`""`)이 포함되어 있을 경우  
  → `[ERROR] 자동차 이름은 공백일 수 없습니다.`
- [x] 자동차 이름이 5자를 초과할 경우  
  → `[ERROR] 자동차 이름은 5자 이하만 가능합니다.`
- [x] 자동차 이름이 중복될 경우  
  → `[ERROR] 자동차 이름은 중복될 수 없습니다.`
- [x] 시도 횟수가 비어 있거나 숫자가 아닐 경우  
  → `[ERROR] 시도 횟수는 숫자여야 합니다.`
- [x] 시도 횟수가 0 이하인 경우  
  → `[ERROR] 시도 횟수는 1 이상의 숫자여야 합니다.`

#### 로직 관련 예외
- [ ] 자동차 목록이 비어 있을 경우  
  → `[ERROR] 경주할 자동차가 없습니다.`
- [ ] 게임 중 예기치 못한 오류 발생 시  
  → `[ERROR] 게임 진행 중 오류가 발생했습니다.`

## 프로그래밍 요구 사항
- [ ] Node.js 22.19.0 이상 버전에서 실행 가능해야 한다.
- [ ] 프로그램 실행의 시작점은 `App.js`의 `run()` 메서드이다.
- [ ] `package.json` 파일은 수정할 수 없다.
- [ ] `@woowacourse/mission-utils`에서 제공하는 API를 사용해야 한다.
  - [ ] 랜덤 값: `MissionUtils.Random.pickNumberInRange(0, 9)`
  - [ ] 입력/출력: `Console.readLineAsync()`, `Console.print()`
- [ ] 외부 라이브러리를 추가하거나 삭제할 수 없다.
- [ ] 함수는 한 가지 일만 하도록 작게 나눈다.
- [ ] indent(들여쓰기) depth는 최대 2까지만 허용한다.
- [ ] 삼항 연산자(`? :`)는 사용하지 않는다.
- [ ] 프로그램 종료 시 `process.exit()`를 사용하지 않는다.
- [ ] Jest를 이용하여 테스트 코드를 작성하고 모든 테스트가 통과해야 한다.
